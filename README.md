# 🛍️ MiniShop

> Мини-магазин электроники — нажимай «Купить», следи за корзиной и суммой.

## 🎯 О проекте

Мини-приложение на чистом JavaScript: витрина с товарами, 
кнопка «Купить» у каждого, и корзина в шапке, которая обновляется в реальном времени.

Проект создан как часть моего портфолио **PortfolioForge** — 
я собираю его постепенно, шаг за шагом.

## 🎮 Как пользоваться

1. Открой `index.html` в браузере
2. Смотри витрину товаров (наушники, клавиатура, мышка, монитор, ноутбук, телефон)
3. Нажми **«Купить»** у любого товара
4. В шапке обновляется:
   - **Товаров** — сколько покупок сделано
   - **Сумма** — общая стоимость в сомах
5. Кнопка меняется на **«В корзине»** и становится зелёной

## 🛠️ Технологии

- HTML5
- CSS3 (Grid-раскладка для витрины, стили для карточек и корзины)
- JavaScript (Vanilla, без библиотек)

## 🧠 Что внутри (логика)

- Массив `products` — 6 товаров с `id`, `title`, `price`, `emoji`
- Цикл `products.forEach(...)` — создает карточки динамически через `document.createElement`
- `card.innerHTML` — шаблонная строка для наполнения карточки
- **Корзина**: две переменные `count` и `total`, которые увеличиваются при клике
- `button.classList.add('bought')` — смена стиля кнопки после покупки
